# Deployment and failure domains
Single active region with three availability zones. CDN/WAF is outside private application subnets. Gateway/load balancer spreads stateless replicas across AZs. Each owned PostgreSQL database has one fenced writer, synchronous in-region standby and read replicas for eligible reads. PgBouncer-style bounded pooling sits in front of writer; stock reads for decisions never go to replicas. Kafka replication factor 3, producer acks=all, min in-sync replicas=2, unclean leader election disabled (proposed settings to validate). Redis failure loses cache/admission hints, not stock; conservatively reduce admission on its outage.
Private data subnets, TLS/service identity, secret manager and outbound provider allowlist. Automated promotion requires synchronous durable replica and old-writer fencing; otherwise stop mutations. Restore and compare payment provider ledger before reopening after regional data loss. RPO/RTO are A10 targets, not exercised results. Autoscale on admitted RPS, pool wait, CPU and consumer lag; pre-warm for scheduled flash sale.
